# Pomodoro タイマー アプリ 開発計画

## 第1段階：基本機能
- Python でポモドーロタイマーのロジックを実装
- 作業時間（25分）と休憩時間（5分）の管理
- タイマーの開始・停止・リセット機能

## 第2段階：UIの実装
- Flask を使った Web アプリケーション化
- HTML/CSS によるタイマー画面の作成
- ブラウザ上でタイマーを操作できる UI の提供

## 第3段階：バックエンドAPI連携
- Flask で RESTful API（開始/停止/リセット/状態取得）を実装
- フロントエンドから API を呼び出す fetch/AJAX 処理を追加
- タイマー状態管理（サーバーサイドでインメモリ管理）
- API 経由で開始/停止/リセット/状態取得が動作し、UI と同期すること
